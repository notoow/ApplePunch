# 품종 안내 문구의 근거

호버/탭 안내는 품종의 일반적인 외관과 맛을 설명합니다.
이 농장의 실측 당도, 저장 기간, 특정 과실의 과육 색을 보장하는 문구는 넣지 않았습니다.

- 부사(후지): 대표적인 후지 계열, 단맛과 과즙. [아오모리현 사과대책협의회 품종 안내](https://www.aomori-ringo.or.jp/wp-content/uploads/2023/07/ringo-ankicho.pdf), [JA 아오모리](https://www.jaaomori.or.jp/tokusan_apple.html).
- 엔부: 짙은 붉은 껍질과 분홍~붉은 과육, 단맛과 산미. [생산업체 평농의 엔부 소개](https://www.pyeongnong.co.kr/product/subpage/apple), [산청군 발표를 보도한 뉴스핌](https://newspim.com/news/view/20261030000730).
- 시나노골드: 황색 과피, 풍부한 과즙, 단맛과 산미의 조화. [육성기관 나가노현 과수시험장](https://www.pref.nagano.lg.jp/kajushiken/jisseki/joho/ringo.html).
- 이지플: 홍로×감홍 국내 육성 품종, 달콤하고 진한 맛. [농촌진흥청 농사로 품종 소개](https://www.nongsaro.go.kr/portal/ps/psb/psby/vodPlay.ps?mvpClipNo=2&mvpNo=851), [국립원예특작과학원 카드뉴스](https://nihhs.go.kr/usr/nihhs/news_Card_view.do?idx=38440).

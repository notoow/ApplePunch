## 당도·산미 점 표시

점 5개는 선택을 돕기 위한 **편집상의 상대적 맛 가이드**입니다.
공인 평점, 브릭스 측정값, 공식 자료의 수학적 환산이나 실제 판매 과실의 등급이 아닙니다.

- 부사: 단맛 중심의 익숙한 대표 품종 → 당도 4, 산미 2.
- 엔부: 단맛과 산미가 함께 느껴지는 품종 → 당도 4, 산미 3.
- 시나노골드: 상대적으로 산뜻한 산미를 느끼는 품종 → 당도 3, 산미 4.
- 이지플: 달콤하고 진한 맛을 안내하는 국내 육성 품종 → 당도 5, 산미 2.
- 감홍: 진한 단맛을 안내하는 국내 육성 품종 → 당도 5, 산미 2.
- 혼합은 구성에 따라 달라지므로 고정된 점수를 표시하지 않습니다.

설명 근거는 `docs/varieties.md`와 [농촌진흥청 감홍 소개](https://www.rda.go.kr/board/board.do?dataNo=100000061040&mode=view&prgId=day_farmprmninfoEntry)를 참고했습니다.
제품 화면에도 일반적인 맛의 경향이며 실측값이 아님을 명시합니다.
